
# Dipasan S.A. - Sitio Web Institucional

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web institucional para Dipasan S.A., una empresa dedicada a brindar servicios de gestión de residuos industriales.

El objetivo es presentar la empresa, dar a conocer sus servicios, mostrar su equipamiento y ofrecer un medio de contacto para potenciales clientes.

El sitio fue desarrollado como Trabajo Final Integrador de la materia Desarrollo Web 1.

## Secciones del sitio

El sitio web está compuesto por las siguientes páginas:

- **Inicio:** presentación general de la empresa.
- **Servicios:** descripción de los servicios ofrecidos.
- **Clientes:** presentación de los sectores y empresas a los que se orientan los servicios.
- **Tecnología:** información sobre maquinaria, vehículos y equipamiento.
- **Gestión de residuos:** descripción de las principales etapas de la gestión de residuos.
- **Contacto:** formulario para realizar consultas.

## Tecnologías utilizadas

Para el desarrollo del proyecto se utilizaron:

- HTML5: estructura y contenido de las páginas.
- CSS3: diseño, estilos y adaptación a diferentes dispositivos.
- JavaScript: funcionalidades interactivas y validación del formulario de contacto.

## Funcionalidades

- Navegación entre las diferentes páginas del sitio.
- Diseño adaptable a distintos tamaños de pantalla.
- Carrusel de imágenes en la página principal.
- Formulario de contacto con validaciones mediante JavaScript.

## Visualización del proyecto

Para visualizar el sitio localmente, se puede descargar o clonar el repositorio y abrir el archivo `index.html` desde un navegador web.
